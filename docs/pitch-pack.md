## 3. Problem

- Global assistants are trained for Western defaults: dollars, US dates,
  Western examples, weak Indian-language reasoning.
- Indian users get confidently wrong answers about local law, exams, prices,
  government schemes — and, worst of all, fabricated scripture.
- Most Indian "AI apps" are thin wrappers with no cultural depth, no citation
  discipline, and no document grounding.

## 4. Solution

Svarga is an assistant layer with an Indian brain:

| Capability | What it means |
|---|---|
| Indian reasoning | ₹, lakhs/crores, IST, DD/MM/YYYY, GST, UPI, RBI/SEBI awareness |
| 39+ languages | Including Hinglish code-switching that actually sounds human |
| Vedic grounding | Cites text, chapter and verse in IAST — refuses to invent a verse |
| Document library | Upload PDF/EPUB, answers come back with citations |
| Baby Krishna buddy | Gita-principled companion mode, safe and non-preachy |
| Memory + learning | Opt-in, consented, privacy-controlled |
| Voice + images | Listening mode, Gita audio mode, image generation |
| Guardrails | Rate limits, moderation, uncertainty markers, no fake confidence |

**Honest technical position:** Svarga orchestrates configured frontier models
and adds its own reasoning standard, memory, retrieval, grounding and safety.
It does not claim to own or independently train base model weights. A consented
fine-tuning path (LoRA adapters on an open base model) is already built and
documented — it activates once real usage produces training data.

Say this plainly in every pitch. It builds more trust than a false claim.
